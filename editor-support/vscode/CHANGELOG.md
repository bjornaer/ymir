# Change Log

All notable changes to the Ymir Language Support extension will be documented in this file.

## [0.1.0] - 2025-11-13

### Added
- Initial release of Ymir Language Support extension
- Syntax highlighting for all Ymir language constructs
- Autocompletion for keywords, built-in functions, and types
- Code snippets for common patterns (functions, loops, classes)
- Real-time diagnostics for syntax errors
- Support for Ymir's concurrency features (channels, spawn, select)
- Support for Ymir's matrix operations
- Language configuration for brackets, comments, and indentation
- Command to run Ymir files from VSCode

### Features
- TextMate grammar for comprehensive syntax highlighting
- Context-aware completion provider
- Diagnostics provider for real-time error checking
- Bracket auto-closing and matching
- Comment toggling with Ctrl+/
- Code folding support
